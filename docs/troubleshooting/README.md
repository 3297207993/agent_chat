# 问题记录（Troubleshooting）

本目录专门记录开发/运行过程中遇到过、且**排查成本较高或容易复发**的问题，避免下次重复踩坑。

## 适用内容

- 环境/系统层面的异常（权限、图形栈、运行时）
- 难以从报错直接定位的启动失败、崩溃、白屏
- 已确认根因、有可复现判断方法的问题

普通的功能 bug、需求变更不放在这里。

## 文件命名

`YYYY-MM-DD-短标题.md`，例如：

- `2026-10-20-webview2-low-integrity.md`

标题用简短英文 kebab-case，正文用中文。

## 文档结构建议

1. **现象**：用户能看到的表现
2. **快速判断**：一条命令/一个检查即可确认
3. **根因**：为什么会这样
4. **解决方案**：可直接复制执行的命令
5. **验证**：怎样确认已修好
6. **复发条件与预防**
