# Agent Chat 界面设计文档

## 1. 布局总览

整体采用**三栏弹性布局**，从上到下依次为顶部工具栏、主内容区（三栏）。

```
┌──────────────────────────────────────────────────────────────────┐
│  顶部工具栏 (44px)                                                │
├────────────┬────────────────────────────────┬───────────────────┤
│  左侧栏    │         内容区                  │   右侧面板         │
│  (260px)   │         (自适应)               │   (300px 可折叠)   │
│            │                                │                   │
│  对话列表  │    ┌──────────────────────┐    │  ┌─ 对话页面 ──┐  │
│  分类过滤  │    │    消息列表          │    │  │ 上下文/工具  │  │
│            │    │    (滚动)            │    │  │ 规则/MCP/记忆│  │
│            │    │                      │    │  └─────────────┘  │
│            │    └──────────────────────┘    │  ┌─ 管理页面 ──┐  │
│            │    ┌──────────────────────┐    │  │ 配置摘要/    │  │
│            │    │    输入框            │    │  │ 统计信息等   │  │
│            │    └──────────────────────┘    │  └─────────────┘  │
└────────────┴────────────────────────────────┴───────────────────┘
```

> **全局面板**：左侧栏和右侧面板均为全局组件，在所有页面中保持一致存在。右侧面板会根据当前路由动态展示不同内容。

---

## 2. 顶部工具栏

### 2.1 左侧
- **应用名称**：显示 "Agent Chat（临时名称，后续需要取一个名字）"

### 2.2 右侧（管理入口按钮组）
- **规则管理** 📋：点击打开规则管理页面（创建/编辑/删除/排序规则）
- **MCP 管理** 🔌：点击打开 MCP Server 管理页面（添加/启停/日志查看）
- **Skill 管理** ⚡：点击打开 Skill 管理页面（内置 Skill 库/导入/自定义）
- **记忆管理** 🧠：点击打开记忆管理页面（浏览/搜索/添加/删除记忆条目）

### 2.3 右侧（功能入口）
- **模型选择器**：下拉选择当前使用的 LLM 模型，按厂商分组，显示模型名称和在线状态
- **设置** ⚙：打开应用设置页面（API Key 配置、主题、语言、快捷键等）

---

## 3. 左侧栏（对话管理）

### 3.1 功能定位
纯对话导航，不包含 MCP/Skill/规则/记忆的任何管理功能。

### 3.2 内容构成

| 组件 | 说明 |
|------|------|
| **新建对话按钮** | 点击创建全新对话，默认使用当前选中的模型 |
| **搜索框** | 按对话标题模糊搜索，实时过滤 |
| **分类标签** | 水平排列的分类标签，如"全部/编程/写作/翻译"，点击筛选对应分类的对话 |
| **对话列表** | 可滚动的对话项列表，每项显示图标、标题、时间，支持置顶 |

### 3.3 对话项交互
- 单击：切换到该对话
- 右键菜单：重命名、变更分类、置顶/取消置顶、删除
- 拖拽：将对话拖拽到分类标签上以变更分类

### 3.4 数据模型
- `Conversation` 包含 `categoryId` 字段，可关联到 `Category`
- `Category` 包含名称、颜色、图标、排序权重

---

## 4. 对话区

### 4.1 消息列表
- 最大宽度 860px，水平居中
- 支持滚动，新消息自动滚动到底部

### 4.2 消息类型

| 类型 | 样式特征 | 说明 |
|------|---------|------|
| **用户消息** | 用户头像 + 纯文本/Markdown | 左对齐，灰色背景头像 |
| **助手消息** | 机器人头像 + 富文本 | 蓝色背景头像 |
| **思考过程** | 紫色左边框 + 灰色背景 + 斜体 | 仅 reasoning 模型展示（如 DeepSeek-R1、Claude thinking） |
| **代码块** | 深色背景 + 语法高亮 + 语言标签 + 复制按钮 | 支持多种编程语言 |
| **工具调用卡片** | 圆角边框 + 状态指示器 + 折叠参数 | 显示工具名称、参数、执行状态、结果 |

### 4.3 消息交互
- 每条消息支持：复制、重新生成（仅助手消息）、编辑（仅用户消息，产生分支对话）
- 工具调用卡片支持展开/折叠查看参数和结果
- 停止生成：流式输出过程中，输入框发送按钮变为停止按钮

### 4.4 输入框

| 功能 | 说明 |
|------|------|
| **文本输入** | 多行文本框，自动调整高度（最小 48px，最大 200px） |
| **附件上传** 📎 | 上传文件（PDF/Word/TXT/代码文件），由多模态模型解析 |
| **图片上传** 🖼 | 上传图片，支持视觉模型 |
| **Skill 触发** | 输入 `/` 弹出 Skill 列表，选择后注入系统提示词 |
| **规则引用** | 输入 `@` 弹出规则列表，手动类型的规则可通过此方式临时引用 |
| **发送** | 点击发送按钮或按 Enter 发送，Shift+Enter 换行 |

## 5. 右侧面板（全局状态面板）

### 5.1 功能定位
全局面板，在所有页面中保持一致存在。根据当前路由动态展示不同内容：
- **对话页面（/）**：展示当前对话的实时上下文状态，5 个 Tab 切换
- **管理页面**：展示对应页面的配置摘要或统计信息

### 5.2 对话页面 Tab 切换
面板顶部有 5 个 Tab 标签，点击切换显示不同内容：

#### 5.2.1 上下文 Tab
- **Token 用量**：进度条显示当前上下文 Token 占用比例（已用/模型上限），下方显示本轮对话累计消耗 Token 数
- **当前 Skill**：显示当前激活的 Skill 名称和描述，无 Skill 时提示"输入 / 触发"
- **系统提示词**：显示当前对话的系统提示词摘要，未设置时提示"未设置"

#### 5.2.2 工具 Tab
- **工具调用历史**：本对话中所有工具调用的时间线列表
- 每条记录显示工具名称、执行状态（运行中/已完成/失败）、调用时间
- 已完成的记录可展开查看参数和返回结果

#### 5.2.3 规则 Tab
- **生效规则列表**：列出当前对话所有生效的规则
- 每条规则标注来源标签：
  - `全局`（蓝色标签）：全局规则，所有对话生效
  - `分类名`（绿色标签）：当前对话所属分类的规则
  - `本对话`（紫色标签）：仅当前对话生效的独立规则
- 规则按优先级排序：本对话 > 分类 > 全局

#### 5.2.4 MCP Tab
- **Server 状态列表**：所有已配置的 MCP Server 及其运行状态
- 状态指示器：绿点 = 运行中，灰点 = 已停止，红点 = 异常
- 每个 Server 显示名称和提供的工具数量

#### 5.2.5 记忆 Tab
- **相关记忆**：与当前对话上下文语义相关的记忆条目
- 每条记忆显示内容摘要和关键词标签
- 无相关记忆时提示"暂无相关记忆"

### 5.3 管理页面摘要面板

当切换到管理页面时，右侧面板显示对应页面的配置摘要或统计信息：

| 页面 | 面板标题 | 展示内容 |
|------|---------|---------|
| 规则管理 `/rules` | 规则概览 | 规则总数、全局规则数、分类规则数 |
| MCP 管理 `/mcp` | MCP 状态 | Server 运行状态、已注册工具数量 |
| Skill 管理 `/skills` | Skill 概览 | 已启用 Skill 数量、触发命令列表 |
| 记忆管理 `/memory` | 记忆概览 | 记忆条目总数、最近访问条目 |
| 设置 `/settings` | 当前配置 | 主题、字体大小、当前 LLM 模型 |
| 调试 `/debug` | 调试信息 | 版本号、框架、构建工具 |

## 7. 响应式与适配

### 7.1 窗口尺寸适配
- 最小窗口宽度：800px
- 小于 900px 时，右侧面板自动隐藏
- 小于 600px 时，左侧栏自动隐藏，可通过汉堡菜单唤出

### 7.2 面板折叠
- **右侧面板**：全局面板，可通过顶部工具栏按钮折叠/展开。收起后内容区占据完整宽度，右侧面板在所有页面中同步隐藏/显示。
- **左侧栏**：全局面板，可通过顶部工具栏的侧边栏按钮或侧边栏顶部的折叠按钮收起。收起后内容区占据完整宽度。
- **两个面板独立控制**：折叠状态互不影响，分别记忆各自的展开/收起状态。

## 8. 交互细节

### 8.1 快捷键

| 快捷键 | 功能 |
|--------|------|
| `Ctrl+N` | 新建对话 |
| `Ctrl+Shift+F` | 搜索对话 |
| `Ctrl+/` | 聚焦输入框并触发 Skill 选择 |
| `Enter` | 发送消息 |
| `Shift+Enter` | 消息换行 |
| `Escape` | 停止生成 / 取消操作 |
| `Ctrl+B` | 切换右侧面板 |
| `Ctrl+Shift+B` | 切换左侧栏 |

### 8.2 加载状态
- 对话列表加载中：骨架屏（skeleton）
- 消息发送中：输入框禁用，发送按钮变为停止按钮
- 流式输出中：逐 token 渲染，光标闪烁动画
- 工具调用中：卡片显示旋转动画和"执行中"状态

### 8.3 空状态
- 无对话时：显示欢迎页面，包含快速开始引导
- 无搜索匹配时：显示"未找到匹配的对话"
- 无规则/记忆/MCP 时：显示引导提示
